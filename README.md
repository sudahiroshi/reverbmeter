# 📐 ReverbMeter - 残響測定アプリ ユーザマニュアル

スマートフォンやパソコンのマイクを使って、室内の**残響時間（RT60）**を手軽に測定できる Web アプリケーションです。

## アプリを開く

1. ブラウザ（Chrome / Safari / Edge / Firefox）で、管理者から共有されたアプリの URL にアクセスします。
2. アプリのトップ画面が表示されれば準備完了です。

> **対応環境**
>
> | 端末 | ブラウザ |
> |------|----------|
> | iPhone / iPad | Safari, Chrome |
> | Android | Chrome, Edge |
> | PC (Windows / Mac) | Chrome, Edge, Firefox, Safari |
>
> ※ マイクが搭載されている端末が必要です。

## 画面の構成

画面下部（またはページ上部）に **3 つのタブ** があります。

| タブ | アイコン | 内容 |
|------|----------|------|
| **測定** | 🎤 | マイクで音を録音し、残響時間を測定します |
| **結果** | 📊 | 最新の測定結果をグラフとともに確認します |
| **データ** | 💾 | 保存した測定結果の一覧表示・エクスポート・削除を行います |

## 測定する

### 測定前に確認すること

「測定」タブの一番上に **📋 測定前に確認すること** のチェックリストがあります。
窓・ドアや空調、端末の持ち方など、結果に影響する項目を測定前に確認できます。
選択中の測定モードに合わせて項目が切り替わり（ピンクTSP では消音モードの解除やイヤホンを外すことなど）、
確認済みの件数が見出しに表示されます。チェックは任意で、見出しをタップすると折りたためます。

### 手順 1：測定モードを選ぶ

「測定」タブを開くと、2 つのモードが表示されます。

| モード | 特徴 | 音源 |
|--------|------|------|
| **👏 インパルス応答** | 手拍子や風船割りなどの短い衝撃音を使います。手軽に測定できます。 | 手拍子など（ユーザが鳴らす） |
| **📡 ピンクTSP** | スピーカーからピンクTSP（ピンク特性の時間引き伸ばしパルス）を再生し、録音した応答に逆フィルタを掛けてインパルス応答を求めます。より精密な結果が得られます。 | 端末のスピーカー（自動再生） |

使いたいモードのボタンをタップして選択してください。

**ピンクTSP モードの測定パラメータ**

「ピンクTSP」を選ぶと、以下の設定が表示されます。既定値のままでも測定できます。

| 設定 | 既定値 | 説明 |
|------|--------|------|
| **信号長** | 約3秒 | 1回に再生する測定信号の長さ。長いほど低域のS/Nが上がり、残響の長い部屋に向きます |
| **開始周波数 / 終了周波数** | 40Hz / 16000Hz | 測定する周波数範囲。端末のスピーカーが出せる範囲に合わせてください |
| **同期加算回数** | 2回 | 加算する周期数。増やすとS/Nが上がりますが、測定時間が長くなります |
| **測定時間の目安** | – | 上記設定から算出した所要時間（信号は「同期加算回数+2」周期ぶん再生されます） |

> **ピンクTSP とは**
>
> パワーが 1/f（オクターブあたり一定エネルギー、-3dB/oct）になるよう設計された測定信号です。
> 白色TSP は高域にエネルギーが偏るため、室内測定では低域のS/Nが不足しやすくなりますが、
> ピンク特性にすることで全帯域で均等なS/Nが得られ、スピーカーの過大入力も避けやすくなります。

### 手順 2：測定を開始する

> 測定ボタンの上の **🧭 測定の手順** に、選択中のモードでの流れが表示されます。
> ピンクTSP では、設定から算出した測定音の長さも表示されます。

1. 画面中央の **「🎤 開始」ボタン** をタップします。
2. 初回アクセス時は **マイクの使用許可** を求めるダイアログが表示されます。**「許可」** をタップしてください。
3. 音圧レベルメーターが動き始め、マイクの入力状況をリアルタイムで確認できます。

### 手順 3：音を鳴らす（インパルス応答モードの場合）

- ステータスが「**待機中**」に変わったら、**手拍子を 1 回** はっきりと鳴らしてください。
- アプリが自動的に衝撃音を検出し、録音・解析を開始します。

> **📡 ピンクTSP モードの場合**
>
> 開始ボタンを押すと、端末のスピーカーからピンクTSP が自動再生されます。
> 音量にご注意ください。再生中は静かにしてください。

### 手順 4：解析完了を待つ

- 解析が完了すると、自動的に「結果」タブに切り替わり、測定結果が表示されます。

### 💡 より正確に測定するためのコツ

- できるだけ **静かな環境** で測定する
- マイク（端末）から **1〜2m 離れた位置** で音を鳴らす
- 手拍子は **1 回だけ**、はっきりと鳴らす
- **エアコンや換気扇** などの背景騒音を止める
- **複数回測定して平均** をとると、安定した結果が得られます

## 結果を確認する

「結果」タブでは、最新の測定結果が表示されます。

### 測定結果サマリー

| 指標 | 意味 |
|------|------|
| **RT60（全帯域）** | 音が 60dB 減衰するまでの時間（秒）。一般的な部屋は 0.3〜1.0 秒 |
| **EDT** | 初期減衰時間。体感的な残響感を示します |
| **適合度 R²** | 減衰曲線を直線で近似したときの当てはまりの良さ。80% を超えることが「有効」の条件です |
| **有効性** | R² が 80% を超え、RT60 が算出できたときに「✓ 有効」、それ以外は「△ 不確実」と表示します |

結果が「△ 不確実」のとき、または入力がクリッピングしたときは、サマリーの下に
**理由**（R² の値、RT60 を算出できなかった、クリッピングの割合など）と、測定モードに合わせた
**改善するには** の案内が表示されます。「🎤 測定タブで再測定する」を押すと、
測定前チェックリストを開いた状態で測定タブに戻ります。

### グラフ

- **🌊 インパルス応答（IR）**：算出したインパルス応答の時間波形（振幅）と、
  dB 表示のレベル曲線 + Schroeder 積分曲線（EDC）を表示します。
  Schroeder 積分曲線がまっすぐ下がっていれば良好な測定です。
  グラフの下には測定信号・周波数範囲・同期加算回数・入力レベル・推定S/N などの測定条件が表示されます。
- **📉 エネルギー減衰曲線（EDC）**：音のエネルギーが時間とともにどう減衰するかを示します。
- **📊 周波数帯別 RT60**：低音〜高音の各周波数帯ごとの残響時間を棒グラフで表示します。

### 💾 測定結果を保存する

1. 結果画面の下部にある **テキスト入力欄** に、測定名（例：「リビング」「会議室A」）を入力します。
2. **「保存」ボタン** をタップします。
3. 保存が完了すると、「データ」タブから確認できます。

## データを管理する

「データ」タブでは、保存済みの測定結果を管理できます。

### 保存データの一覧

保存された測定結果が一覧表示されます。各データには測定名、日時、RT60 値が表示されます。

### データのエクスポート

保存データをファイルとしてダウンロードできます。

1. エクスポートしたいデータのチェックボックスを選択します（「すべて選択」も可能）。
2. ツールバーのボタンからフォーマットを選びます。
   - **📄 CSV**：表計算ソフト（Excel など）で開けるカンマ区切り形式
   - **📋 JSON**：プログラムで扱いやすい JSON 形式

### データの削除

1. 削除したいデータのチェックボックスを選択します。
2. **「🗑️ 削除」ボタン** をタップします。
3. 確認ダイアログで承認すると、選択したデータが削除されます。

> ⚠️ 削除したデータは元に戻せません。必要なデータは事前にエクスポートしてください。

## その他の機能

### 🌙 テーマ切替（ダークモード / ライトモード）

画面右上の **🌙 ボタン** をタップすると、ダークモードとライトモードを切り替えられます。お好みの表示テーマでご利用ください。

### ❓ ヘルプ（使い方ガイド）

画面右上の **❓ ボタン** をタップすると、アプリ内ヘルプが表示されます（初めてアプリを開いたときも自動で表示されます）。
ヘルプは **1 概要 → 2 準備 → 3 測定 → 4 結果** の 4 ステップに分かれており、「次へ」「戻る」または上部のステップボタンで切り替えられます。

| ステップ | 内容 |
|----------|------|
| 1 概要 | 残響時間（RT60）とは、このアプリでできること、測定の流れ |
| 2 準備 | 測定前に確認すること、端末別のマイク許可手順 |
| 3 測定 | インパルス応答方式・ピンクTSP方式の手順、正確に測るコツ |
| 4 結果 | 結果の見方、「△ 不確実」と表示されたとき、保存と書き出し |

## よくある質問

### Q. マイクの許可ダイアログが表示されません

ブラウザの設定でマイクのアクセスがブロックされている可能性があります。以下を確認してください。

- **iPhone Safari**：「設定」→「Safari」→「マイク」で許可を確認
- **Android Chrome**：アドレスバー左の 🔒 アイコン → 「サイトの設定」→「マイク」を許可
- **PC Chrome**：アドレスバー左の 🔒 アイコン → 「マイク」を許可に変更

この手順はアプリ内の ❓ ヘルプ、またはマイクのエラー表示にある「端末別のマイク許可手順を見る」からも確認できます。

### Q. 「開始」を押すとマイクのエラーが表示されます

測定ボタンの下に、原因に応じた案内が表示されます（× で閉じるか、次に「開始」を押すまで表示されます）。

| 表示 | 原因と対処 |
|------|------------|
| マイクの使用が許可されていません | ブラウザでマイクがブロックされています。上記の手順で許可してから再読み込みしてください |
| マイクが見つかりません | マイクが接続されていないか、OS の入力デバイスが無効です。接続・設定を確認してください |
| 安全な接続（HTTPS）で開かれていません | `http://` のページではマイクを使えません。`https://` の URL で開き直してください |
| マイクを開始できませんでした | ほかのアプリがマイクを使用中などの理由で開始できませんでした。ほかのアプリを終了し、再読み込みしてください |

### Q. 測定結果が「△ 不確実」と表示されます

以下の原因が考えられます。

- 背景騒音が大きすぎる → より静かな環境で再測定してください
- 手拍子の音が小さすぎる → マイクに近づいて、はっきり鳴らしてください
- 適合度（R²）が 80% 以下 → 上記の「正確に測定するためのコツ」を参考に再測定してください
- 「録音レベルが低すぎます」と表示される → マイクがミュートされていないか、入力音量が小さすぎないかを確認してください
- 「クリッピングしています」と表示される → 再生音量またはマイクの入力レベルを下げて再測定してください

### Q. データはどこに保存されますか？

測定データはお使いの端末の **ブラウザ内（LocalStorage）** に保存されます。以下の点にご注意ください。

- ブラウザのデータを消去すると、保存データも消えます
- 別の端末や別のブラウザからは保存データにアクセスできません
- 大切なデータは **CSV または JSON でエクスポート** して保管することを推奨します
- 算出したインパルス応答（波形データ）はアプリ内に保持されますが、まだ保存・アップロードには対応していません

### Q. スマートフォンでも使えますか？

はい、スマートフォン（iPhone / Android）の標準ブラウザでそのままご利用いただけます。アプリのインストールは不要です。
